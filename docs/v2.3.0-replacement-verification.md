## 3. 性能验证

优化仅在单次计算内缓存父路径/防环结果，并建立远端 ID、目录 key 和最长前缀规则索引；不跨事务缓存可变树，不改全局歧义规则。

环境：Windows x64、Node v24.20.0、Intel i7-13700KF。每个场景预热一次、测量三次；同一主机逐对运行，表中为中位数。准备和断言不计入计时。

| 合成场景 | 优化前 | 优化后 |
|---|---:|---:|
| 10,000 节点平衡树路径 | 96.7 ms | 27.5 ms |
| 300 层链状路径 | 462.4 ms | 0.7 ms |
| 10,000 节点无改动合并规划 | 1,967.3 ms | 476.6 ms |
| 100 个目录同时改名 | 840.0 ms | 371.4 ms |

共 13 组优化前后成对基准、26 个计时结果，以及 600 组路径语义对照（重复 ID、环、虚拟根、区域根、缺父及旧编码）。均检查输出树、节点数、路径唯一性与输入不变。仓库中的 7 项性能回归使用操作次数预算和行为断言，避免把机器速度作为测试成功条件。

上述数据不是手机端、真实 Chrome 书签 API 或网络性能承诺，不能与修复前不同测量条件的单次跟踪数字混用。

## 5. 直接复查结论与边界

正确性复查重点是恢复副本生命周期、提交前后故障、桥接身份/父引用、精确删除版本及目标关系隔离。架构上让三种手机桥接共享身份算法，让传输共用期限和提交状态判断，减少旧的全局标题/URL 猜测及重复实现。性能改动用语义对照和计数回归约束。安全边界核对了输入验证、路径作用域、安装包允许文件集及私钥排除；没有新增依赖，也没有将外部输入当成操作授权。

在本次已复现问题和回归范围内，未发现仍阻止发布的缺陷；**这不等于证明没有其他问题**。以下限制仍然存在：

1. 未进行真实手机、浏览器 GUI、生产 WebDAV 厂商兼容性、宿主后台生命周期或长时间运行验证。隔离 IO 测试不代表 Aira / Via / Berry 实机 UI 验收。
2. 不具备跨所有客户端通用的持久全局节点身份。无充分证据时不猜改名，旧路径歧义时不删，可能保留冲突副本或暂缓删除传播。
3. 新旧客户端混用未验证；旧客户端不能理解新斜杠路径和完整恢复/删除规则，相关设备应统一更新。
4. PUT 的 202 / 207 不做后台逐项确认；超时/断连可能已经提交，必须报告未知结果，不自动重试。
5. 同版本替换不会自动触发版本递增更新；签名 ID 稳定不等于每个宿主都允许同版本覆盖安装。
6. 现有 Vitest 1.6.1 开发工具的已知安全公告未在本次处理；它及其依赖不进入扩展包，本次不是完整供应链审计。
