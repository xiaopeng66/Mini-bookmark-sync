# v2.3.1 发布说明

本版修复「上次本地事务尚未完成」把同步拦住却无处恢复的问题，并清理操作记录里的误报。

## 修复与改进

### 本地恢复

- 同步被「上次本地事务尚未完成」拦下时，弹窗与设置页会给出恢复入口，不再只报一句失败。
- 设置页新增「本地书签恢复」：显示未完成备份的保存时间、同步文件夹与书签数量，可先只读检查、导出当前书签与备份，确认后才执行恢复。
- 检查后确认无需补回任何书签时按成功处理，不再显示失败，随后可以继续同步。
- 书签已经同步完成、只有完成状态没保存上的情况，只补记完成状态，不用旧备份覆盖当前书签，也不会撤销之后的新增和删除。
- 恢复前先保存一份当前书签副本；目标文件夹或云端账户与备份不一致时拒绝改动书签，原备份与副本都保留。
- 恢复与上传、下载、合并共用同一队列，不会互相打断；失败后重试不会覆盖最初保存的副本。

### 操作记录

- 「云端未提供强 ETag」这类能力提示不再进入设置页的操作记录，也不再显示成红色的「操作失败」。
- 真正的同步失败、云端冲突，以及写入保护级别的说明仍然保留。

## 验证与限制

- **910/910 JavaScript 测试通过，50 个测试文件**。
- **6/6 打包工具测试通过**；生产 JavaScript 语法与差异空白检查通过。
- 验证运行真实生产模块，Chrome API、存储与网络为隔离模拟；本次没有操作真实书签或生产 WebDAV。
- **没有完成真实手机、浏览器 GUI、生产 WebDAV 厂商兼容性验证**，不承诺不存在其他缺陷。
- 恢复入口的界面交互经过隔离页面验证，不等同于真机安装验证。
