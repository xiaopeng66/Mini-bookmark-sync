# 2.4.0

这一版修好跨设备移动书签的位置同步，并让手机端在浏览器不支持移动时不再丢书签。

## 更新内容

### 更新

- **启动同步**：浏览器打开、配置检查通过后自动额外同步一次，不必等定时间隔到点。
- **本地书签恢复**：设置页可查看未完成的事务备份、导出当前书签与备份，确认后再恢复。

### 优化

- **移动方向**：以「上次同步时这个书签在哪里」为准，本机残留的旧移动记录不再反向覆盖云端。
- **移动识别**：剪切/粘贴式移动、网址只差末尾斜杠、移动的同时改标题，都识别为同一次移动。
- **手机端移动**：宿主不支持直接移动时按多种调用形式依次重试，支持任意一种即可自动同步位置。
- **同步提示**：能力降档提示同一级别只提示一次；同步进行中不再误报「有未完成的本地事务」。
- **写入基线**：上传/合并提交后的基线改记「实际写进云端的树」，同步等待期间的新移动不会被迁回。

### 修复

- **不再丢书签**：移动无法落地时明确报错并原样保留两端书签，去掉了会误删书签的自动重建。
- **写回前复核**：有一处移动不在云端的新位置就停止写回，云端保持原样。
- **恢复收尾**：检查确认无需补回时按成功处理，已完成而状态没保存的只补记状态。
