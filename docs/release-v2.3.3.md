# v2.3.3 发布说明

本版修复移动书签后另一台设备收不到、云端反被旧位置覆盖的问题。

## 修复与改进

### 移动书签/文件夹

- 一台设备把书签或文件夹移到别处并同步后，另一台设备同步时能拿到新位置，不再把旧位置写回云端。
- 移动方向以「上次同步时这个书签在哪里」为准：本机自上次同步后没动过它，就跟随云端的新位置，不再被本机残留的旧移动记录反向覆盖。
- 剪切/粘贴式移动（新建副本再删掉原书签、书签编号会变）同样能同步到其他设备。
- 书签网址只差末尾斜杠、或「移动的同时改了标题」时，也能识别为同一次移动，不会在旧文件夹留下一份副本。
- 同步等待期间用户又拖动书签时，不会再被误记成「已同步的位置」，下一轮不会把这次移动还原。

桌面已解压安装请先备份配置，将下载的文件更新到**原安装目录**，再到扩展管理页点「重新加载」。不同安装方式的 ID 可能不同，不要仅因名称相同就卸载旧扩展；卸载会清除配置。手机安装、更新及配置保留由宿主决定，本次未实机验证。参与同步的设备建议统一更新。
