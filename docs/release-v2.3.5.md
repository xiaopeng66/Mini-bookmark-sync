# v2.3.5 发布说明

本版修复手机端移动书签失败时可能把书签删掉的问题，并减少重复提示。

## 修复与改进

### 移动书签/文件夹

- 手机端宿主不支持直接移动书签时，会先新建一份并确认它真的出现在新文件夹里，确认之后才删除原书签；确认不了就保留原书签并中止，不会再出现「书签被删掉」。
- 重建后旧文件夹里不会再残留一份同名副本。
- 写回云端前会再核对一次位置：只要有一条书签不在云端的新位置，就停止写回，云端保留原样。
- 失败时不再留下「未完成的本地事务」：移动校验在导入之前完成，回滚范围小，失败后可以直接重试。

### 提示

- 「本服务未提供可用的并发校验」这类说明**同一级别只提示一次**，不再每次同步都重复；服务能力变化时会重新提示。

## 验证与限制

- **933/933 JavaScript 测试通过，51 个测试文件**。
- **6/6 打包工具测试通过**；生产 JavaScript 语法与差异空白检查通过。
- 验证运行真实生产模块，Chrome API、存储与网络为隔离模拟；本次没有操作真实书签或生产 WebDAV。
- **没有完成真实手机、浏览器 GUI、生产 WebDAV 厂商兼容性验证**，不承诺不存在其他缺陷。
