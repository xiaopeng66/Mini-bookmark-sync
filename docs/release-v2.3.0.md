# v2.3.0 发布说明

本版重点提升书签同步的恢复安全、跨端一致性和大树处理性能，修复目录改名、移动、删除传播与异常恢复等问题。

## 修复与改进

### 恢复与删除安全

- 尚未恢复完成的事务备份禁止被下一次同步覆盖；失败后重试不再丢失唯一恢复副本。
- 同步桶被重建并获得新 ID 后，继续恢复仍能找到原备份，且不会接管无关同名目录。
- 同步基线保存失败时保留原始历史树和所属关系；后台重启后的删除仍有证据，不用当前树冒充丢失的历史基线。
- 同步桶与主页互相包含时，下载重建保护内层容器，回滚不再重复删除同一个物理节点。
- 失败回滚只撤销本次事务新建的内容，保留用户并发新增；公开恢复与上传、下载、合并共用串行互斥，不再互相打断。
- 上传先绑定本次目标关系，再读取该关系的云端时间戳，避免切换目标后误覆盖或误报冲突。

### Berry / Via / Aira 桥接一致性

- 使用共同的路径和身份判定，手机端目录改名、移动或书签编辑不再丢失子层级；有可靠历史身份时保留桌面节点 ID。
- 手机删除后明确重新添加同一书签，可依据已确认的删除版本撤销旧记录；不会顺带清除并发发生的新删除。
- 依据真实树迁移旧斜杠路径快照；歧义旧键不能授权删除。
- 修复 Aira 路径碰撞去重及悬空父引用，统一重映射父节点和顺序引用，并保留原生扩展字段。
- 手机写回快照以实际成功写出的内容为准；Via 两份文件都确认成功后才提交联合基线，桥接部分失败会明确报告。

### 目录、顺序与解析

- 父文件夹改名与另一端删除子书签或调整顺序同时发生时，删除记录和三方顺序比较使用统一身份，避免书签复活或顺序回退。
- 移动到本轮新建目录时，先创建父链再移动，保留原文件夹层级。
- 修复目录身份消歧、父改名后的内容更新和反方向移动层级问题；独立新目录不能仅因内容相似而被误当成改名。
- XBEL 合法结束标签空白可以正确读取；Via 严格检测截断或畸形 HTML，同时保留合法引号、属性及 URL 字节。
- 保留 XBEL / URL 解析、桥接读取完整性和 WebDAV 路径边界保护。

### 网络与提交边界

- 主同步及桥接传输设置包含请求和正文读取的 45 秒期限，挂起请求不再永久占住同步队列；看门狗不把仍在运行的任务误报为空闲。
- 显式可重试的瞬时失败，不论以异常还是失败结果返回，均能进入有限重试。冲突、提交结果未知、提交后部分失败或恢复未完成时不盲目重跑。
- PUT 仅以 200 / 201 / 204 确认提交；202 / 207 报告未确认，PUT 超时或断连报告结果未知，不能推进成功基线。
- 主文件已确认写入后，元数据、桥接快照或状态保存失败改报部分完成，并继续可完成的基线收尾，不回滚已经确认的提交。

### 性能

减少路径祖先扫描、远端 ID 反查和改名匹配中的重复排序/遍历，缓存仅限单次计算。Windows 隔离基准中，10,000 节点无改动合并规划的中位数约从 **1,967 ms 降到 477 ms**；300 层路径计算约从 **462 ms 降到 0.7 ms**。这些是合成数据测量，不是手机或真实网络耗时承诺。

## 验证与限制

- **845/845 JavaScript 测试通过，46 个测试文件**。
- **6/6 打包工具测试通过**；生产 JavaScript 语法与差异空白检查通过。
- 性能验证包含 600 组路径语义对照和 13 组优化前后成对基准。
- 验证运行真实生产模块，Chrome API、存储、网络及时间为隔离模拟；本次没有操作真实书签或生产 WebDAV。
- **没有完成真实手机、浏览器 GUI、生产 WebDAV 厂商兼容性及长期运行验证**，不承诺不存在其他缺陷。
- 无可靠身份或旧路径有歧义时保守保留数据，可能暂缓一次删除传播；跨版本客户端混用未验证。
- 202 / 207 不做后台提交确认或逐项轮询。若提示写入结果未知，应先核对云端，再决定下一次操作。
