# v2.3.0 发布说明

本版针对 2026-10-11 全链路审计报告中的高优先级问题，集中修复会直接造成**书签复活、丢失或恢复时互相删除**的几类缺陷。

## 修复与新增

- 父文件夹改名与另一端删除子书签同时发生：删除记录随改名投影到新路径，被删书签不再复活。
- 父文件夹改名与另一端调整顺序同时发生：三方顺序比较改用同一身份，顺序不再回退。
- 移动到本轮新建的父文件夹：新父及其祖先先落地再移动，原文件夹层级保持完整。
- 同步桶与主页互相嵌套时执行「下载重建」：不再误删内层容器，失败回滚可精确还原。
- 失败回滚只撤销本次同步新建的内容；同步期间手动新增的书签不再被回滚删掉。
- 手动「恢复」与下载/合并改为排队执行，不再互相打断；恢复可重建缺失的主页/同步桶容器。
- 一并修复读取与写入边界问题：XBEL 合法空白/CDATA/重复 ID、URL 实体二次解码、桥接读取不完整仍覆盖、路径含 `#` 或 `%2e%2e` 写到基路径之外。

## 验证

640/640 自动化测试通过，打包工具回归测试通过；源码语法、版本和修复标记检查通过，四种安装包及桌面解压目录已独立校验与源码一致。

其中 54 条新增回归测试在 v2.2.2 的代码上运行会失败，确认对应缺陷确实存在于上一版；本版修复后全部通过。

## 安装

| 你在用什么 | 装哪个 |
|---|---|
| 桌面 Edge / Chrome | `minibookmark-sync-2.3.0-chromium-sideload.zip` |
| 手机 可拓 / 雨见等 | `minibookmark-sync-2.3.0.1-gecko-mv2-persistent.xpi` |
| 手机 Firefox | `minibookmark-sync-2.3.0-gecko-mv2.xpi`（未签名，能否安装取决于宿主） |

桌面已解压安装请将文件更新到原目录，再到扩展管理页点「重新加载」。手机安装由宿主浏览器确认，取决于其支持与签名要求；以相同扩展 ID 覆盖升级时可保留配置，卸载后重装会清除配置。

附带 Chromium `.crx` 和 `SHA256SUMS.txt`。手机安装流程未在本机实机验证。
