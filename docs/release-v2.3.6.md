# v2.3.6 发布说明

本版停止在手机端自动「删除后重建」书签，改为移动失败时明确报错并原样保留。

## 修复与改进

### 移动书签/文件夹

- 手机端宿主无法直接移动书签时，不再自动新建一份再删除原书签；这一做法在部分手机浏览器上会因宿主回滚新建节点而导致书签消失。
- 现在会先重发一次移动并复核；仍不落地就明确报「本机未能把书签移动到云端的新位置，已停止写回云端以保护书签」，本机与云端的书签都保持原样。
- 如果之前的版本已经因此少了一条书签：云端仍保留着它，下一次合并会自动导回本机。

## 验证与限制

- **933/933 JavaScript 测试通过，51 个测试文件**。
- **6/6 打包工具测试通过**；生产 JavaScript 语法与差异空白检查通过。
- 验证运行真实生产模块，Chrome API、存储与网络为隔离模拟；本次没有操作真实书签或生产 WebDAV。
- **没有完成真实手机、浏览器 GUI、生产 WebDAV 厂商兼容性验证**，不承诺不存在其他缺陷。
