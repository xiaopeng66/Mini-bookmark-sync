# v2.3.8 发布说明

本版修掉同步过程中误报的「有未完成的本地事务」卡片。

## 修复与改进

### 同步提示

- 同步进行中不再显示「有未完成的本地事务。旧备份已保留，请检查后再同步。」这张卡片。事务备份在同步开始时本来就是「未完成」状态，那是正常的中间态，不是需要处理的问题。
- 只有同步已经结束、事务确实没有收尾时才会提示，此时打开「本地书签恢复」检查即可。
- 同步速度本身没有变化；之前看到的「先弹卡片、过一会成功」只是提示时机的问题。

## 验证与限制

- **936/936 JavaScript 测试通过，51 个测试文件**。
- **6/6 打包工具测试通过**；生产 JavaScript 语法与差异空白检查通过。
- 验证运行真实生产模块，Chrome API、存储与网络为隔离模拟；本次没有操作真实书签或生产 WebDAV。
- **没有完成真实手机、浏览器 GUI、生产 WebDAV 厂商兼容性验证**，不承诺不存在其他缺陷。
