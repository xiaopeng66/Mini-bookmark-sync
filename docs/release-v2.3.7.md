# v2.3.7 发布说明

本版让移动操作在更多手机宿主上真正生效，并明确失败的下一步。

## 修复与改进

### 移动书签/文件夹

- 移动书签时依次尝试多种调用形式（带 index、数值型父节点编号、`browser.*` Promise 版、无回调 Promise 版）；宿主只要支持其中任意一种，位置就能自动同步过去。
- 所有形式都不生效时明确报错并保留本机与云端书签，不删除、不重建、不写回。
- 手机上移动没能自动生效时，打开弹窗点「下载」即可：下载按「云端删除记录删旧 + 建新」落地位置，不依赖移动接口。

## 验证与限制

- **935/935 JavaScript 测试通过，51 个测试文件**。
- **6/6 打包工具测试通过**；生产 JavaScript 语法与差异空白检查通过。
- 验证运行真实生产模块，Chrome API、存储与网络为隔离模拟；本次没有操作真实书签或生产 WebDAV。
- **没有完成真实手机、浏览器 GUI、生产 WebDAV 厂商兼容性验证**，不承诺不存在其他缺陷。

## 安装

| 宿主 | 安装附件 |
|---|---|
| 桌面 Edge / Chrome | `minibookmark-sync-2.3.7-chromium-sideload.zip` |
| 手机可拓 / 雨见等支持对应形态的宿主 | `minibookmark-sync-2.3.7.1-gecko-mv2-persistent.xpi` |
| 手机 Firefox | `minibookmark-sync-2.3.7-gecko-mv2.xpi`（未签名，能否安装取决于宿主） |

另附 Chromium `.crx`、本说明和 `SHA256SUMS.txt`，下载后可核对文件校验值。

桌面已解压安装请先备份配置，将下载的文件更新到**原安装目录**，再到扩展管理页点「重新加载」。不同安装方式的 ID 可能不同，不要仅因名称相同就卸载旧扩展；卸载会清除配置。手机安装、更新及配置保留由宿主决定，本次未实机验证。参与同步的设备建议统一更新。
