# v2.3.2 发布说明

本版修复在两台设备之间移动书签/文件夹后位置被还原的问题，并让浏览器启动后自动同步一次。

## 修复与改进

### 移动书签/文件夹

- 在一个文件夹里把书签（或文件夹）拖到另一个文件夹，同步后另一端能拿到新位置，不再被还原到原处。
- 同步进行中拖动书签也会被正确记录，不再因为「正在同步」而丢失这次移动。
- 移动方向改由「本次移动记录 + 上次同步时的位置」共同判断：即使浏览器没有派发移动事件、或隔了很久才同步，也不会把本机刚做的移动当成需要跟随云端的旧位置。
- 源文件夹里只有这一个书签时，移动同样会写回云端并传播到其他设备。
- 归位判定额外要求同一个书签的本地编号一致：在别处新建的同名同网址书签不会被误当成「移动」而把原书签搬走。

### 启动同步

- 浏览器打开后，只要自动同步已开启且 WebDAV 配置完整，会额外同步一次，不必等到定时间隔到点。
- 与「错过补跑」不会重复执行：同一轮启动只对齐一次云端。
- 配置不完整或自动同步关闭时不发请求，原因写入自动同步实况（设置页诊断报告可见）。

## 验证与限制

- **923/923 JavaScript 测试通过，51 个测试文件**。
- 验证运行真实生产模块，Chrome API、存储与网络为隔离模拟；本次没有操作真实书签或生产 WebDAV。
- **没有完成真实手机、浏览器 GUI、生产 WebDAV 厂商兼容性验证**，不承诺不存在其他缺陷。

桌面已解压安装请先备份配置，将下载的文件更新到**原安装目录**，再到扩展管理页点「重新加载」。不同安装方式的 ID 可能不同，不要仅因名称相同就卸载旧扩展；卸载会清除配置。手机安装、更新及配置保留由宿主决定，本次未实机验证。参与同步的设备建议统一更新。
