# v2.3.4 发布说明

本版修复移动书签后手机端同步失败、云端被旧位置覆盖的问题。

## 修复与改进

### 移动书签/文件夹

- 手机端在同步时如果没能真正把书签移到云端的新位置（部分浏览器会返回成功但实际不动），现在会先复核，再按「先建后删」的方式重建落地，不再把旧位置写回云端。
- 重建仍失败时明确报「本机未能把书签移动到云端的新位置，已停止写回云端以保护书签」，云端保留新位置，不会用旧位置覆盖。
- 文件夹移动无法重建时同样中止本轮写回，绝不偷偷删除文件夹内容。
- 一次移动落到多条书签时逐条校验，只要有一条没落地就停止写回云端。

## 验证与限制

- **931/931 JavaScript 测试通过，51 个测试文件**。
- **6/6 打包工具测试通过**；生产 JavaScript 语法与差异空白检查通过。
