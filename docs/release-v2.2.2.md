# v2.2.2 发布说明

## 修复与新增

- 修复同一文件夹内只调整书签或文件夹顺序时无法正确同步的问题，包含存在主页内容时的顶层换序。
- 修复两端节点编号冲突造成子树遗漏、重复或顺序异常的问题。
- 新增设置页「版本更新」：检查最新版并下载当前扩展变体的安装包。
- 完善更新检查的超时、稳定版本识别、联网权限、缓存恢复与失败提示。

## 验证

579/579 自动化测试通过，打包工具 5/5 回归测试通过；源码语法、版本和修复标记检查通过，四种安装包及桌面解压目录已独立校验与源码一致。

## 安装

| 你在用什么 | 装哪个 |
|---|---|
| 桌面 Edge / Chrome | `minibookmark-sync-2.2.2-chromium-sideload.zip` |
| 手机 可拓 / 雨见等 | `minibookmark-sync-2.2.2.1-gecko-mv2-persistent.xpi` |
| 手机 Firefox | `minibookmark-sync-2.2.2-gecko-mv2.xpi`（未签名，能否安装取决于宿主） |

桌面已解压安装请将文件更新到原目录，再到扩展管理页点「重新加载」。手机安装由宿主浏览器确认，取决于其支持与签名要求；以相同扩展 ID 覆盖升级时可保留配置，卸载后重装会清除配置。

附带 Chromium `.crx` 和 `SHA256SUMS.txt`。手机安装流程未在本机实机验证。
